# Advanced Topics on Computer Architecture Lab

This repo contains the lab exercises for the course *"Advanced Topics on Computer Architecture*" of the **Department of Computer Engineering & Informatics** in **University of Patras**.

## Overview
1. **Lab 1:** Extention of RV32I ISA and simulation using gem5 simulator.
   - Through-the-stack flow of adding and simulating new CPU instructions (riscv-gnu-toolchain, gem5).
   - Used a Makefile to facilitate tests.
2. **Lab 1:** Microarchitectural Performance Analysis using gem5 simulator.
   - Evaluated performance bottlenecks of compute and memory-intensive workloads on InOrder and Out-of-Order RISC-V pipelines.
   - Profiled the impact of cache hierarchies, Reorder Buffer (ROB) capacity and Physical Register File (PRF) sizes on workload performance.
   - Developed bash and Python scripts, along with a Makefile to orchestrate and parallelize the experiment execution.

## File explanation
1.	The folder *"Lab1"* contains the first lab exercise.
1.	The folder *"Lab2"* contains the second lab exercise.
